# PhiMC 交互重构方案（v2）

> 现状问题：F8 无反应、F9 击打反人类、只支持压缩包不支持 Phira 生态。
> 本方案目标：**右键物品开始 → 鼠标点击判定 → 结算**，并把 Phira 的开源资产用起来。

---

## 1. 为什么 F8 没反应

三个可能，按概率排序：

| 可能 | 说明 | 处理 |
|---|---|---|
| 键位被其它 mod / 输入法占用 | F8 是很多 mod 和笔记本的媒体键 | 不再依赖 F8 |
| 键位只在游戏内 tick 生效，标题界面按了没反应 | `ClientTickEvents.END_CLIENT_TICK` 只在世界里跑 | 属于设计问题 |
| 玩家没在“控制”里看到这个键位分类 | Fabric 键位分类名未本地化，容易被忽略 | 不再依赖键位 |

结论：**主入口改成物品 + 右键菜单**，键位只留一个“打开选曲”（默认 `P`，可在控制里改）。

---

## 2. 入口：物品

### 2.1 物品定义

```
phimc:chart_player        // 谱面播放器（暂用"唱片"的外观，后续换贴图）
```

获得方式（三选一，全给）：

1. **创造模式物品栏**新增一个页签「PhiMC」
2. 指令 `/give @s phimc:chart_player`
3. 首次进世界时自动放进背包（可在配置里关）

### 2.2 交互

- **右键** → 打开选曲界面（`Screen`）
- **潜行 + 右键** → 直接开始上次玩的曲子
- 选曲界面里：曲名 / 曲师 / 难度（EZ HD IN AT）/ 物量 / 时长 / 最佳成绩
- 点条目 → 开始；Esc 返回

选曲界面用原版 `Screen` + `ButtonWidget` 列表实现，不引入额外 UI 库。

## 3. 游玩输入（核心改动）

### 3.1 方案 A：鼠标点击（推荐，最接近 Phigros）

- 音符是 2D 下落，判定线固定在屏幕下方
- **左键点击**：取鼠标的屏幕 x 坐标，落在音符 x 的容差内（±0.06 屏宽）且时间在窗口内 → 判定
- **按住不放**：Hold 持续判定，抬手提前 → 断连
- **快速横移**：Flick（鼠标 x 速度 > 阈值）
- **扫过即触发**：Drag（不需要点击）

技术上需要拦截鼠标事件。两条路：
- `Screen` 子类接管输入（开始游戏时打开一个透明 `Screen`，它自己处理 `mouseClicked` / `mouseDragged` / `mouseReleased`）——**推荐**，不需要 mixin，风险低
- Mixin 到 `Mouse`（更底层，但版本敏感）

### 3.2 方案 B：四轨键盘（备选，可同时提供）

`D F J K` 对应四条轨道，音符按 x 分到最近的轨。适合不想动鼠标的人，也方便录屏。

### 3.3 建议

**默认方案 A，设置里可切方案 B。** 判定窗口沿用现有 `Judgement.Config`（Perfect 80ms / Good 160ms / Bad 200ms），并加一个“延迟校准”滑条（±150ms），写回 `config/phimc/config.json`。

## 4. 渲染

| 项 | 现在 | 目标 |
|---|---|---|
| 判定线 | 固定水平线 | 支持 `judgeLineMoveEvents` / `RotateEvents` / `DisappearEvents`（`Engine` 已经算好了） |
| 音符 | 纯色方块 | 贴图（Tap/Drag/Hold/Flick 各一张）+ Hold 尾条 |
| 打击特效 | 无 | 命中扩散圈 + 判定文字 |
| combo / 分数 | 左上角文字 | 居中 combo + 右上分数 |
| 进度条 | 无 | 底部细条 |

贴图用 `assets/phimc/textures/gui/note_*.png`，先程序生成（圆角矩形 + 描边），后续可换美术。

## 5. 用起来 Phira 的开源

| Phira 资产 | 用途 |
|---|---|
| `.pez` 包格式（zip：`info.yml` + `chart.json` + `music.ogg` + `illustration.png`） | **把 mod 的导入格式扩成 pez**，玩家直接从 Phira 生态拿谱，不用再找“谱面包” |
| 判定窗口 / 灰度判定常量 | 对照 Phira 源码对齐手感数值 |
| 判定线事件求值的实现 | 交叉验证我们 `Engine` 的事件插值 |
| 谱面转换工具链（官方谱 → pez） | 已有谱面批量转换 |

落地动作：
1. `SongEntry` 增加 `.pez` 分支：读 `info.yml`（简化的 YAML：只解析 `name/level/composer/illustration/music/chart` 几个键）+ `chart.json` + 音频
2. 支持“把 `.pez` 直接拖进 `songs/`”
3. 用 Phira 的一份真实 pez 做回归测试

> 注意：`.pez` 里的音频多为 ogg，现有 `OggToWav`（stb_vorbis + JavaSound）已能处理。

## 6. 里程碑

| 阶段 | 内容 | 预估 |
|---|---|---|
| **M1** | 物品 + 创造页签 + 右键打开选曲 `Screen` + 点条目开始 | 1 轮 |
| **M2** | 透明 `Screen` 接管鼠标：点击/按住/滑动判定，位置匹配 | 1 轮 |
| **M3** | 判定线 move/rotate 渲染 + 音符贴图 + Hold 尾条 | 1–2 轮 |
| **M4** | 结算界面（分数/评级/各判定/最大连击）+ 延迟校准设置 | 1 轮 |
| **M5** | `.pez` 导入 + 用真实 pez 回归 | 1 轮 |

M1 做完你就能“拿物品右键开玩”，不必再碰 F8。
