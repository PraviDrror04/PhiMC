# PhiMC 生存玩法设计（v3：按「谱面」售卖）

> v3 改动（用户确认）：**交易单位是「谱面」= 曲目 + 难度**，不是曲子。
> 一首曲子有几个难度就是几个独立商品，可以分开买；不存在「买一首送四难度」。

---

## 1. 核心概念

| 概念 | 例子 | 说明 |
|---|---|---|
| 曲目 | `Verruckt` | 一首歌 |
| **谱面** | `Verruckt#IN` | 曲目 + 难度 = **交易/解锁的最小单位** |
| 曲库 | 已拥有谱面的集合 | 按曲目分组显示 |

**一首曲子有几个谱面完全取决于 `songs/` 里实际放了什么**：
- 常见是 4 个（EZ/HD/IN/AT），但**只有 1 个谱面的曲子同样合法**（比如只做了 IN）
- 也可能只有 2 个（EZ + HD）、3 个（缺 AT）
- 程序不做「必须有 4 个」的假设，曲库里有几个就显示几行

一首曲子理论上可以只在商店卖 IN，不卖 EZ——取决于货架刷到什么。

## 2. 物品

### 2.1 平板（`phimc:tablet`）

```
紫水晶碎片  玻璃板  紫水晶碎片
红石粉      铁锭    红石粉
铜锭        铁锭    铜锭
```

- 不可堆叠，耐久 200（每首歌 −1，铁砧 + 铜锭修）
- 右键打开界面；潜行右键 = 重打上一首

### 2.2 谱面芯片（`phimc:chart_chip`，可选）

交易后可以选择拿芯片（NBT 存 `chartId = 曲目#难度`），丢进平板解锁。
默认直接解锁，芯片是可选的「可交易形态」。

## 3. 界面

### 3.1 曲库
按曲目分组，**有几个谱面就几行**（不做 4 难度假设）：

```
Verruckt            EZ  ✓  S 0987300
                    HD  ✓  A 0912000
                    IN  ✓  PHI 1000000  FC
                    AT  ???
```

- 拥有的难度显示成绩，可点开始
- 未拥有的显示灰色 `???`，旁边提示「商店有售」或「已售罄/未上架」

### 3.2 商店
- 每天刷 6 个**未拥有谱面**
- 每行：`曲目 · 难度` ｜ 标价（物品图标 × 数量）｜ 买得起/买不起
- 点一下：背包够就扣物品、解锁该谱面
- 买不起提示「还差 X 个 Y」

### 3.3 设置
延迟校准、宽判练习、音量。

## 4. 定价（每个谱面独立随机）

```java
long seed = hash(chartId, worldSeed);   // chartId 形如 "Verruckt#IN"
Random r  = new Random(seed);
ItemPool pool = POOLS[difficulty];      // EZ/HD→0, IN→1, AT→2
Item item = pool.pick(r);
int count = pool.countFor(item, r);
```

| 难度 | 物品池 | 数量 |
|---|---|---|
| EZ / HD | 铁锭、铜锭、红石粉、煤炭、玻璃板、面包 | 3–12 |
| IN | 金锭、青金石、紫水晶碎片、黏液球、蜂蜜瓶 | 2–8 |
| AT | 钻石、下界石英、熒石粉、末影珍珠、经验瓶 | 1–4 |

- 同一 `chartId` 在同一世界内价格固定（改存档也改不了，价格是纯函数算出来的）
- 不同难度同一首歌的价格互不相关

## 5. 生存世界

- 洞穴/水下打歌：判定窗口 ×1.3，收益（若有）更高
- 附近 16 格有敌对生物：不能开始
- 每首歌消耗平板耐久 1 点
- 结构掉落：废弃音乐教室（随机 EZ/HD 芯片）、末地城市（AT 芯片）、远古城市（旧磁带 → 隐藏曲）

## 6. 存档

```json
{
  "worldSeed": 88172645463325252,
  "unlocked": ["Verruckt#EZ", "Verruckt#HD", "Verruckt#IN"],
  "records": {
    "Verruckt#IN": { "score": 987300, "acc": 98.42, "fc": true, "combo": 1200 }
  },
  "shopSeed": 1734567890,
  "shopRefreshAt": 1712390000,
  "tabletDurability": 187
}
```

价格不进存档，由 `worldSeed + chartId` 现算。
