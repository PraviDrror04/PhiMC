# PhiMC

在 Minecraft 里打音游谱面的 Fabric 模组：判定线、音符、Tap / Hold / Drag / Flick 判定、连击计分、特效谱渲染、在线谱面库、生存玩法，全部自己实现。

支持 **1.20 ~ 1.21.11 共 19 个 Minecraft 版本**。

> **本项目不附带任何谱面、音乐或美术素材。**
> 谱面与音频由玩家自行放入 `config/phimc/songs/`，版权归各自作者所有。

## 特性

| 能力 | 说明 |
|---|---|
| 谱面格式 | PGR（`formatVersion` 1/3）、RPE（Re:PhiEdit `.pez`）、PEC（文本谱面），自动识别 |
| 音频 | WAV / OGG / MP3（纯 Java JLayer），解码失败会退化成墙钟兜底，不会卡死时间轴 |
| 判定 | 判定线本地坐标系、`0.08 / 0.16 / 0.22` 窗口、Early/Late、Hold 尾判定、Flick/Drag 语义 |
| 渲染 | 判定线移动/旋转/透明度/速度/缩放、音符 alpha/可见时间/尺寸/染色、贴图判定线、文字线（含打字机）、zOrder、颜色事件 |
| 输入 | 鼠标 / 触屏式拖拽、键盘（恒开）、空格甩键 |
| 在线谱面库 | 内置 Phira 社区搜索、下载、曲绘预览、上架/未上架筛选 |
| 生存玩法 | 平板合成、商店购买谱面、芯片拷贝与解锁、开箱掉落、评级奖励 |
| 界面 | 选曲（曲绘/详情/搜索/排序/筛选）、设置、结算、游戏内 HUD |
| 版本 | 19 个 MC 版本，一个安装器全兼容 |

## 安装

### 方式一：安装器（推荐）

双击 `PhiMCSetup.exe`：

1. 自动定位 `.minecraft`（不对可以点「浏览」）
2. 选实例 —— 安装器会读取该实例的 MC 版本，自动装 `mods/phimc-<MC>.jar` 与对应版本的 Fabric API
3. 点「安装」
4. 点「打开资源包文件夹」，把材质包 `.zip` 放进去（可选）

> 安装器会在安装前清掉 `mods/` 里同 mod id 的旧 jar（按 jar 内 `fabric.mod.json` 的 id 判断，不只按文件名），所以升级不会出现两个版本打架。
> 不在 1.20 ~ 1.21.11 范围内的实例会被明确拒绝，不会装错。

### 方式二：手动

1. 装好 **Fabric Loader** + 对应版本的 **Fabric API**
2. 把 `phimc-<你的MC版本>.jar` 放进 `mods/`
3. 启动游戏

首次启动会自动创建 `config/phimc/`。

## 怎么玩

### 1. 拿到入口物品

三种方式任选：

- **创造模式**：`PhiMC` 物品页签里的 **谱面播放器**
- **生存**：工作台合成 **平板**（见[生存玩法](#生存玩法)），右键打开
- **指令**：`/give @s phimc:chart_player`

### 2. 选曲

打开界面后选一首谱面，点「开始」。

- 曲库是空的？见[谱面放进哪里](#谱面放进哪里)
- 在线页签可以直接搜索下载

### 3. 打歌

音符沿判定线落下，在判定线附近按准。

- **鼠标**：左键点击 / 按住拖动
- **键盘**：`D F J K`（Tap/Hold），`Space`（Flick）
- **Drag**：需要在判定线附近有输入（不会自动判 Perfect）

结算会给出分数、评级、连击、准确率。

## 谱面放进哪里

```
.minecraft/config/phimc/songs/
```

支持：

- **`.pez` 文件**（RPE / PEC / PGR 打包，自带音频与曲绘）
- **`.zip` 曲包**（内部含 `chart.json` + `info.txt` 或 `meta.json` + 音频）
- **文件夹**（解压后的谱面目录）

放进去后回到选曲界面按「刷新」。

> 音频通常就在谱面包里。如果谱面只有 `chart.json` 没有音频，请把音频和它放在同一目录。

## 操作

| 操作 | 按键 |
|---|---|
| 打开选曲 | `P` |
| Tap / Hold | `D` `F` `J` `K` |
| Flick | `Space` |
| 暂停 / 继续 | `Esc` |
| 重开 | 结算界面按钮 |

鼠标同样可用：点击判定线上的音符、按住保持 Hold、快速划动触发 Flick。

## 设置

选曲界面 → 「设置」：

| 项 | 说明 |
|---|---|
| 判定偏移 | `-300ms ~ +300ms`，步进 10ms。`＋` = 谱面提前（音符更早到判定线） |
| 打击音量 | 默认较低（-15 dB），避免盖过音乐 |
| 打击音开关 | 关掉就只有音乐 |
| 材质包 | 选择 `config/phimc/respack/` 里的 `.zip`，旁边有「打开文件夹」 |
| 自动游玩 | 只演示、不写成绩、不发奖励 |

> 判定偏移是**全局**的（跟设备走），谱面解锁与成绩是**按存档**独立的。

## 在线谱面库

选曲界面 → 「在线」页签：

1. 输入关键词（曲名 / 谱师）后回车
2. 列表带曲绘、难度、评分、谱师
3. 点「下载」→ 自动落到 `songs/` → 列表自动刷新

右上角有 **「仅上架」** 开关：

- 开（默认）：只显示已上架、已过审的谱面
- 关：连未上架的也显示，行内灰字标注 `[未上架]`

> 在线谱面的版权归各自作者，本项目只做检索与下载。

## 生存玩法

### 平板

工作台合成：

```
紫水晶碎片   玻璃板   紫水晶碎片
红石粉       铁锭     红石粉
铜锭         铁锭     铜锭
```

右键平板 → 商店 / 曲库。平板有耐久（打歌消耗）。

### 商店

用物品购买谱面，价格按谱面随机（同一存档内固定，重开不变）。

### 芯片

```
铁锭  红石  铁锭
      铁锭
      金粒
```

→ **空芯片**

流程：

```
平板曲库里对「已解锁」的谱面点「拷芯片」
  → 空芯片变成「谱面芯片」（一芯一谱，不可改写）
  → 右键谱面芯片解锁该谱面（芯片不消耗，可重复用）
```

箱子战利品里也能开出**已经载好某张谱面**的芯片（打开箱子那一刻随机赋谱）。
普通箱子 25%、稀有结构箱 50%。

### 奖励

按评级发物资（含解锁谱面所需的物品）。自动游玩不发奖励。

### 赠送

新平板赠送 2 首可下载曲目。

## 资源包（打击音 / 音符贴图）

把材质包 `.zip` 放进：

```
.minecraft/config/phimc/respack/
```

然后在设置页选择它。包里如果有同名音频（`hit_click.ogg` 等）会优先用包里的。

没装材质包也能听到底噪打击音（内置）。

## 常见问题

**谱面看不见 / 列表是空的**
检查是不是放进了 `config/phimc/songs/`，然后在选曲界面点「刷新」。

**打歌时谱面时间不动、音符不来**
多半是音频解码失败。看日志里 `[PhiMC] 音频播放失败`，把那个谱面文件发 issue。

**某些贴图线显示成纯色块**
部分谱面会故意放蒙版图（`mask_*.png`、`black.png`），那是谱面本身的效果。

**换存档后解锁没了**
解锁与成绩是**按存档**的，属于设计行为。全局只有设置项。

**联机时进度不保存**
多人 / 专用服务器下拿不到本地存档路径，进度只读。单人存档正常。

**没装正版能联机吗**
原版「对局域网开放」强制验证账号。需要装 `OfflineLAN` 之类的模组才能关掉在线模式。

## 从源码构建

### 环境

- JDK 25（Loom 1.19.2 要求）
- Gradle 9.8.2（Stonecutter 要求）
- `GRADLE_USER_HOME` 建议单独指定

### 构建

```bash
# 全部 19 个版本（逐版本串行，别一次并行，会 OOM）
cd mod
./build.ps1

# 单个版本
gradle :1.21.1:build
```

产物：`mod/dist/phimc-<MC>.jar`

### 目录

```
core/        纯 Java 引擎（解析 / 判定 / 音频），零 Minecraft 依赖
mod/         Fabric 侧（Stonecutter 多版本）
docs/        设计与验证报告
tools/       headless 探针与校验脚本
setup/       安装器源码（C#）
lib/         第三方 jar（gson / JLayer / JWebP）
```
